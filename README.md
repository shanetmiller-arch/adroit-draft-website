## Product Stub Architecture

The product portfolio uses a stub architecture pattern:

1. **Data Source**: `products.js` contains the `productStubs` array defining all products
2. **Renderer**: `ProductManager.renderProducts()` dynamically renders product cards
3. **Extensibility**: Add new products by extending `productStubs` with required fields

### Product Schema

Each product requires:
- `id`: unique identifier (e.g., 'pmris', 'rmfm')
- `name`: short product name
- `fullName`: complete product name
- `description`: brief product description
- `phase`: development phase (Phase 1, Phase 2, etc.)
- `status`: current status (planned, active, dev)
- `category`: product category
- `features`: array of feature strings
- `imageUrl`: path to product image
- `statusBadge`: CSS class for status styling
